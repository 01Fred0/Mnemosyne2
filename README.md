# Mnemosyne - 3D Memory Palace Construction Kit

## Overall Description
Mnemosyne is an innovative 3D spatial memory application that transforms how users organize and recall information by creating immersive, navigable 3D environments for memory palaces. This cutting-edge application combines advanced 3D graphics with cognitive science principles to create powerful spatial memory aids. Users can construct personalized 3D environments where digital representations of files, documents, images, and ideas are placed in memorable spatial arrangements that enhance recall and learning.

The application features a sophisticated 3D editor that allows users to build custom memory palaces using modular room systems, with different room types (square, round, hexagonal) that can be connected in a grid-based layout. Each room can contain interactive 3D objects representing files, folders, images, and documents that users can place throughout their memory palace.

## Key Features and Functions

### 3D Memory Palace Construction
*   **Modular Room System**: Create interconnected 3D spaces using predefined room modules (SquareRoom, RoundRoom, HexRoom, corridors).
*   **Grid-Based Snapping**: All rooms and objects snap to a precise world grid for easy construction and organization.
*   **Scalable Architecture**: Support for complex multi-room memory palaces with customizable layouts.
*   **Room Customization**: Per-room ambiance settings including lighting, audio, and environmental effects.

### Spatial Organization System
*   **File Representation**: Transform digital files into interactive 3D objects that can be placed spatially.
*   **Object Placement**: Position documents, images, folders, and audio files as physical objects in 3D space.
*   **Spatial Navigation**: Navigate through memory palaces using intuitive first-person controls (WASD + mouse look).

### Interactive 3D Environment
*   **First-Person Navigation**: WASD movement controls with mouse look, sprint, jump, and gravity physics.
*   **Object Interaction**: Raycast-based interaction system for picking up, moving, and manipulating 3D objects.
*   **Drag-and-Drop Interface**: Intuitive file and folder import via drag-and-drop from OS file system.
*   **Gizmo-Based Editing**: Visual manipulation tools for precise object positioning and scaling.

### Advanced Graphics and Audio
*   **Dynamic Lighting**: Per-room directional lights, point lights, and ambient lighting with post-processing effects.
*   **Shadow Mapping**: Real-time shadow rendering for enhanced 3D depth perception.
*   **Post-Processing**: Bloom effects, color grading, and atmospheric effects.
*   **Spatial Audio**: 3D positional audio for immersive room ambiance.
*   **Skybox Environments**: Custom skybox backgrounds for each memory palace room.

### Technical Architecture
*   **Modern C++ Engine**: Built with C++20 and OpenGL 4.6 Core Profile for optimal performance.
*   **Component-Based Design**: Modular architecture organized into logical subsystems.
*   **Cross-Platform Core**: Designed with a portable core architecture, with optimized support for Windows 10.
*   **Real-time Rendering**: Forward rendering pipeline with efficient culling and batching systems.

### Core Systems
*   **Physics Engine**: Custom AABB collision detection for realistic movement and interaction.
*   **Resource Management**: Intelligent asset loading and caching system for optimal performance.
*   **Serialization**: JSON-based save/load system for persistent memory palaces.
*   **Input Management**: Comprehensive input handling for both navigation and editing.
*   **Audio System**: Integrated spatial audio with miniaudio for room ambiance and object interaction.

### User Experience Features
*   **Editor Interface**: Full-featured editor with docking panels for professional-grade 3D content creation.
*   **Undo/Redo System**: Complete command pattern implementation for non-destructive editing.
*   **Real-time Preview**: Instant visual feedback during editing with hot-reloading capabilities.
*   **Performance Optimized**: Optimized for systems with Intel Core i7-4810MQ and AMD Radeon HD 8950 graphics.

## System Requirements
*   **Operating System**: Windows 10 (Primary target)
*   **Processor**: Intel Core i7-4810MQ CPU @ 2.80GHz
*   **Graphics**: AMD Radeon HD 8950 + Intel HD Graphics 4600 (2GB total graphics memory)
*   **Storage**: 100GB free storage on hard drive
*   **Memory**: 16GB RAM
